# @mechane/ui-layout

Responsive application framing without routing or resource ownership.

`AppShell` owns the collapsible sidebar and mobile drawer. `PageToolbar` owns the continuous bottom separator and its
action layout. `DetailPage` sets readable content width. Navigation accepts links supplied by the application, while
branding and workspace choices belong to `console-views`.

See the [component guide](../../../docs/components.md) and colocated Storybook examples.
