# @mechane/ui-charts

Generic charts built with visx and shared Mechane presentation tokens.

`Waterfall` accepts interval, point, or unavailable geometry, stable item identities, caller labels, and controlled
selection. Textual timing accompanies the visual marks. The caller owns units, ordering, and domain meaning; the
Console's request adapter maps recorded request evidence into these presentation values.

See the [component guide](../../../docs/components.md) and the Waterfall stories.
