# @mechane/ui-tokens

Shared StyleX definitions for the supported light theme.

Import definitions directly from `@mechane/ui-tokens/tokens.stylex` so StyleX can resolve them at compilation. Colors,
typography, spacing, control dimensions, radii, and motion belong here. Shell geometry stays with `@mechane/ui-layout`;
chart scales take numeric values from their callers.

React is a development dependency for the colocated catalog only. See the
[component guide](../../../docs/components.md).
